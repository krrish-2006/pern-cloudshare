# CloudShare - PERN Media App

A full-stack file upload application where users can securely register, log in, and manage their own image gallery.

**Live Demo:** https://pern-cloudshare.vercel.app/

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS (Deployed on Vercel)
- **Backend:** Node.js, Express, JWT Auth (Deployed on Render)
- **Database:** PostgreSQL via Supabase
- **Media Storage:** Cloudinary

## Features
- JWT-based user authentication
- Protected routes and user-specific data isolation
- Image upload with Multer and Cloudinary
- Image validation (backend and frontend)
- Gallery view and image deletion
